# 同学 · 一起想，一起答

清爽的课堂同步答题网页。老师线下提问，学生写下答案；本轮参与者全部提交后，服务器自动揭晓所有答案。

## 使用

1. 老师选择“我是老师”，填写称呼并创建课堂。
2. 分享 6 位课堂码或邀请链接。学生填写名字加入，所有人可见课堂名单。
3. 学生姓名与随机设备凭据保存在浏览器 localStorage；再次访问会自动返回上次课堂。无需验证姓名。
4. 老师线下提问，点击“开始第一轮”。本轮锁定参与名单，中途加入者下轮参与。
5. 学生提交后不可修改。揭晓前，API 只返回提交状态和访问者自己的答案，不返回其他人的答案。
6. 最后一名参与者提交时，服务器切换到揭晓状态，所有页面在约 2 秒内同步展示答案。
7. 老师可以开启下一轮。已完成的上一轮保存到 classroom_rounds 表，当前轮保存在 classrooms 表。

离线学生仍在本轮名单中，避免断线导致提前揭晓。老师可确认移出离开的同学，移出后不再等待其答案。教师权限依赖创建课堂时保存在该浏览器的随机凭据；请保留老师使用的浏览器数据。清除本地数据或换设备会产生新身份。每个课堂最多 60 位学生。

## 技术与检查

React / Vinext + Cloudflare Workers + D1。轮次与答案通过数据库 revision 条件更新，防止并发提交覆盖。服务器只存设备凭据的 SHA-256 摘要，API 不向其他成员返回凭据。学生不能执行开始轮次、移出成员等教师操作。

- `npm run dev -- --hostname 127.0.0.1`：本地预览。
- `npx tsc --noEmit`：类型检查。
- `python3 tests/classroom_api.py`：针对本地 5173 服务的多人集成检查。
- 新数据库先应用 drizzle 下的迁移，正式部署由 Sites 执行迁移。

`.openai/hosting.json` 保留 Sites 项目标识和 D1 绑定。正式访问策略由 Sites 管理；应用本身不要求学生账号。当前线上课堂公开访问，无需 ChatGPT 登录。

## 浏览器直传作业

教师在课堂下方点击「开始接收作业」，学生填写学号并发送 `.ipynb`（nbformat 4，单份最大 20 MB）。文件通过 WebRTC DataChannel 传给教师浏览器；服务器只保存短期连接描述，不保存文件正文。教师的接收会话每 2 秒续期，20 秒无心跳后失效；停止接收会关闭现有连接，刷新教师页面后需要重新开启。

接收端校验字节数、SHA-256 和 Notebook 格式，IndexedDB 事务提交后才向学生发送成功确认。文件保存在教师当前浏览器、当前网站的本地存储里，刷新后可恢复，每次重交保留独立记录。请使用收件列表的「下载」按钮另存备份；清理浏览器网站数据、换浏览器或换网站地址不能恢复原浏览器里的副本。传输成功与已下载到磁盘是不同状态。学号和原有姓名均由学生填写，不验证真实身份。

支持 Cloudflare TURN 兜底，最多同时接收 4 个连接，其余请求等待；超时后学生可重试。启用中继后浏览器自动选择直连或中继，连接失败不会显示提交成功。上线课堂前仍应在实际师生网络验证。

检查：`node tests/file-signaling.mjs`、`npx tsc --noEmit`、`python3 tests/files_api.py`（需本地 5173 预览）。若工作目录在云同步盘，可通过 `CLASSROOM_PREVIEW_STATE=/tmp/classroom-file-preview` 指定独立预览数据库目录，先对该目录应用 drizzle 迁移；线上数据库不受此选项影响。

教师可点击「全部下载（ZIP）」一次导出当前课堂、本浏览器保存的全部收件。ZIP 按学生分目录，保留每次提交，并附带不含浏览器凭据的 `提交清单.json`，记录原始文件名、提交编号、接收时间与 ZIP 内路径。打包期间新到的文件不加入当前导出；单份下载仍可用。


## Cloudflare TURN

生产密钥由 Sites 环境变量管理，不写入仓库：`CLOUDFLARE_TURN_KEY_ID`、`CLOUDFLARE_TURN_API_TOKEN`、`TURN_TEACHER_PASSPHRASE`。前两项来自 Cloudflare Realtime TURN 专用 key，最后一项是教师开启中继时输入的共享密钥。不是 Cloudflare Global API Key。

教师开启接收时可选填 TURN 密钥，无需 ChatGPT 登录。服务端验证正确才为该接收会话启用中继；留空、错误密钥或服务未配置均只开启直连，并向教师明确显示结果。密钥仅发送到后端验证，不保存到课堂状态或浏览器持久存储，开启后清空输入框。学生仍用课堂码进入。`files-ice` 要求有效课堂身份、当前接收会话和教师心跳，返回每成员独立的 10 分钟临时凭据。凭据在服务端缓存，在有效期剩余不足 3 分钟时更新；每成员新申请至少间隔 15 秒，使用数据库 revision 原子占位防止并发重复签发。普通课堂/信令响应不包含任何 TURN 凭据。主 API Token 只用于服务端调用 Cloudflare。

停止接收关闭浏览器连接并停止签发凭据，但不立即撤销已签发的临时凭据。课堂码和浏览器身份不是实名身份验证，短期凭据在有效期内也可能被复制，需在 Cloudflare 控制台关注额度使用。

未配置密钥时保留原来的直连功能。Cloudflare API 异常时显示重试提示，不假报中继已就绪。凭据响应过滤浏览器不支持的端口及非 Cloudflare 主机。测试包括 `node tests/cloudflare-turn.mjs`；`tests/files_api.py` 在未配置 TURN 的本地环境检查认证与回退。

## 本地开发与 CI

需要 Node.js 24 LTS、npm 和 Python 3（API 测试仅使用标准库）。

```sh
npm ci
npm run typecheck
npm test
npm run test:integration
npm run build
```

`test:integration` 自动创建临时 D1 数据库、应用迁移、在 127.0.0.1:5173 启动服务，检查课堂权限、答案保密、并发提交、文件信令隔离和未配置 TURN 时的直连回退。结束后关闭服务并删除临时数据；请先停止占用 5173 的本地服务。测试不需要 Cloudflare 账号或生产密钥。

交互式开发时，先初始化本地数据库：

```sh
npx wrangler d1 execute DB --local --config wrangler.local.json --file drizzle/0000_little_patriot.sql
npm run dev -- --hostname 127.0.0.1
```

GitHub Actions 在 push 和 pull request 时运行上述类型检查、单元测试、API 集成测试及生产构建，不自动部署网站。单元测试覆盖接收租约、教师权限、TURN 密钥验证及凭据过滤、ZIP 内容和安全路径。CI 不覆盖真实跨网络 WebRTC 穿透；发布前仍需用师生实际网络验证文件传输与下载。

不要提交 `.env*`、`.dev.vars*` 或真实 TURN 凭据。此仓库的生产部署仍由 Sites 管理；`.openai/hosting.json` 中的项目标识不属于密钥，克隆代码不会获得该项目的管理权限。独立部署需要配置自己的 Workers/D1 和可选 TURN 环境变量。

## Markdown 课堂黑板

课堂顶部的黑板由教师编辑，点击「发布给全班」后，已加入的学生在约 2 秒内看到更新。支持标题、列表、加粗、链接、图片、表格、任务列表和代码块；原始 HTML 不执行，危险链接由渲染器过滤。教师拥有本地即时预览，学生只能看到已发布版本。

已发布内容保存在课堂数据库，刷新、学生后加入和开启新答题轮次均保留。草稿只存于教师当前浏览器；失败时保留草稿，轮询不会覆盖输入。每次最多 10000 字。编辑区清空后发布即可擦除黑板。多页面编辑使用独立黑板版本检测冲突，避免旧草稿覆盖新内容；发生冲突时先复制草稿，再点击「载入已发布内容」重新编辑。

`npm run test:integration` 包含 `tests/blackboard_api.py`：验证教师权限、学生可见性、长度校验、轮次保留、后加入学生、课堂隔离、并发编辑冲突和清空黑板。

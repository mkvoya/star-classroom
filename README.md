# 同学 · 一起想，一起答

清爽的课堂同步答题网页。老师线下提问，学生写下答案；本轮参与者全部提交后，服务器自动揭晓所有答案。

## 使用

1. 老师选择“我是老师”，填写称呼并创建课堂。
2. 分享 6 位课堂码或邀请链接。学生填写名字加入，所有人可见课堂名单。
3. 学生姓名与随机设备凭据保存在浏览器 localStorage；再次访问会自动返回上次课堂。无需验证姓名。
4. 老师线下提问，点击“开始第一轮”。本轮锁定参与名单，中途加入者下轮参与。
5. 学生提交后不可修改。揭晓前，API 只返回提交状态和访问者自己的答案，不返回其他人的答案。
6. 最后一名参与者提交时，服务器切换到揭晓状态，所有页面在约 2 秒内同步展示答案。
7. 老师可以开启下一轮。已完成的上一轮保存到 classroom_rounds 表，当前轮保存在 classrooms 表。

离线学生仍在本轮名单中，避免断线导致提前揭晓。老师可确认移出离开的同学，移出后不再等待其答案。教师权限依赖创建课堂时保存在该浏览器的随机凭据；请保留老师使用的浏览器数据。清除本地数据或换设备会产生新身份。每个课堂最多 60 位学生。

## 技术与检查

React / Vinext + Cloudflare Workers + D1。轮次与答案通过数据库 revision 条件更新，防止并发提交覆盖。服务器只存设备凭据的 SHA-256 摘要，API 不向其他成员返回凭据。学生不能执行开始轮次、移出成员等教师操作。

- `npm run dev -- --hostname 127.0.0.1`：本地预览。
- `npx tsc --noEmit`：类型检查。
- `python3 tests/classroom_api.py`：针对本地 5173 服务的多人集成检查。
- 新数据库先应用 drizzle 下的迁移，正式部署由 Sites 执行迁移。

`.openai/hosting.json` 保留 Sites 项目标识和 D1 绑定。正式访问策略由 Sites 管理；应用本身不要求学生账号。当前发布为私有预览，公开访问需所有者确认。

## 浏览器直传作业

教师在课堂下方点击「开始接收作业」，学生填写学号并发送 `.ipynb`（nbformat 4，单份最大 20 MB）。文件通过 WebRTC DataChannel 传给教师浏览器；服务器只保存短期连接描述，不保存文件正文。教师的接收会话每 2 秒续期，20 秒无心跳后失效；停止接收会关闭现有连接，刷新教师页面后需要重新开启。

接收端校验字节数、SHA-256 和 Notebook 格式，IndexedDB 事务提交后才向学生发送成功确认。文件保存在教师当前浏览器、当前网站的本地存储里，刷新后可恢复，每次重交保留独立记录。请使用收件列表的「下载」按钮另存备份；清理浏览器网站数据、换浏览器或换网站地址不能恢复原浏览器里的副本。传输成功与已下载到磁盘是不同状态。学号和原有姓名均由学生填写，不验证真实身份。

当前使用 STUN 辅助直连，最多同时接收 4 个连接，其余请求等待；超时后学生可重试。尚未配置 TURN，因此不同网络、校园隔离网络或受限 NAT 下可能无法直连。上线课堂前请用实际师生网络验证；需要跨网兜底时再接入带短期凭据的 TURN 服务。连接失败不会显示提交成功。

检查：`node tests/file-signaling.mjs`、`npx tsc --noEmit`、`python3 tests/files_api.py`（需本地 5173 预览）。若工作目录在云同步盘，可通过 `CLASSROOM_PREVIEW_STATE=/tmp/classroom-file-preview` 指定独立预览数据库目录，先对该目录应用 drizzle 迁移；线上数据库不受此选项影响。

教师可点击「全部下载（ZIP）」一次导出当前课堂、本浏览器保存的全部收件。ZIP 按学生分目录，保留每次提交，并附带不含浏览器凭据的 `提交清单.json`，记录原始文件名、提交编号、接收时间与 ZIP 内路径。打包期间新到的文件不加入当前导出；单份下载仍可用。
